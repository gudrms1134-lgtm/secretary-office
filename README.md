# 형근님 비서실 — 사용 안내

`index.html` 파일 하나로 동작하는 멀티 비서실 웹 앱입니다. 서버·빌드 없이 브라우저에서 열면 바로 쓸 수 있습니다.

**휴대폰 설치용 주소(PWA):** <https://gudrms1134-lgtm.github.io/secretary-office/> — 열고 브라우저 메뉴에서 '홈 화면에 추가'

## 여는 방법

- **PC**: `index.html` 더블클릭 (Chrome/Edge 권장)
- **휴대폰**: 파일을 폰으로 옮겨 브라우저로 열기
- **배포**: 이 폴더를 그대로 GitHub Pages / Vercel / Netlify에 올리면 됩니다. (정적 호스팅, 별도 설정 없음)

## 메뉴

| 탭 | 내용 |
|---|---|
| 💬 회의실 | 3개 채널(대회의실·지휘실·라운지) 대화. 채널별로 따로 저장됩니다. |
| 📋 작업실 | 작업 카드 추가 → 시작(진행중) → 완료, 되돌리기, 삭제. 끌어서 옮겨도 됩니다. |
| 📊 비서현황 | 비서 4명의 상태·연결 모델·최근 응답 시간·응답 횟수 |
| 📝 메모 | 자유 메모 작성·수정·삭제 |

## 회의실 사용법

1. **발신** 칩에서 화자를 고릅니다. 기본은 `👑 형근 (대장님)`입니다.
2. **멘션** 칩(`@all`, `@빵근비서`, `@챗GPT`, `@제미나이`, `@클로드`)을 누르면 입력창에 들어갑니다.
3. 메시지를 보내면 지목된 비서가(멘션이 없으면 총괄 빵근비서가) 먼저
   **"네, 대장님! 실행하겠습니다."**로 응답하고, 이어서 각자 성격에 맞게 답합니다.

## AI 연결 (⚙️ API 설정)

키가 없으면 **데모 모드**로 응답합니다. 데모 모드에서도 **채널의 앞뒤 대화를 읽고 이어서** 답합니다(인사·잡담·질문·후속 대답·지시를 구분하고, "아까 내가 뭐라고 했어?"처럼 물으면 실제 앞 발화를 인용). 키를 넣으면 실제 모델이 답합니다.

| 방법 | 키 | 사용되는 비서 |
|---|---|---|
| **Gemini 키 하나 (가장 간단)** | `AIza...` 또는 `AQ....` | **4명 전부** (빵근·챗GPT·제미나이·클로드 — 각자 역할·말투 유지) |
| OpenRouter | `sk-or-v1-...` | 4명 전부 (빵근·챗GPT·제미나이·클로드) |
| 개별 키 | OpenAI `sk-...` | 빵근비서, 챗GPT 비서 |

- **Gemini 키 하나면 4명 전원이 실제 AI**: 자동 모드에서 OpenRouter·OpenAI 키가 없어도, Gemini 키만 있으면 빵근·챗GPT·클로드까지 Gemini 모델을 호출합니다(각 비서의 역할·말투는 system prompt로 유지). 상단 칩이 `실제 AI 연결 (4/4)`로 바뀝니다.
- **Gemini 기본 모델**: `gemini-flash-lite-latest` (무료 등급·저지연). 단종·혼잡(404/503)이면 `gemini-3.5-flash-lite` → `gemini-3.8-flash` 순으로 자동 재시도합니다. 모델 지정을 비우면 이 값이 쓰입니다.
- **키 전달 방식**: `x-goog-api-key` 헤더로 보내며 `AIza…`·`AQ.…` 두 형식 모두 동작합니다.

- **연결 모드**: `자동`(입력된 키 우선, Gemini 키 하나로도 4명 전원) / `OpenRouter` / `개별 키`(전용 키 우선, 없으면 Gemini 키로 대체) / `데모`
- **맥락 전달**: 실제 모드에서는 채널의 최근 **20개** 대화를 함께 보냅니다.
- **무료로 쓰기**: OpenRouter 무료 계정은 `:free` 모델만 호출됩니다. 유료 모델을 부르면 402(결제 필요) 오류가 나고, 채팅에 "OpenRouter 충전이 필요하거나 무료 모델(:free)로 변경해야 합니다" 안내가 남습니다.
- **모델 지정**을 펼치면 비서별 모델명을 직접 바꿀 수 있습니다. 비워두면 기본값을 씁니다.
  - 기본값(OpenRouter): `openai/gpt-4o-mini`, `google/gemini-2.0-flash-001`, `anthropic/claude-3.7-sonnet`
  - 기본값(Gemini 키 사용 시): 4명 모두 `gemini-flash-lite-latest`
- **🔌 연결 테스트**로 키가 실제로 동작하는지 바로 확인할 수 있습니다.
- API 호출이 실패하면(키 오류·CORS 차단 등) 응답을 데모로 대체하고 채팅에 안내 문구를 남깁니다.

> 키는 이 브라우저의 `localStorage`에만 저장되고 서버로 전송되지 않습니다.
> 대화·작업·메모도 모두 이 브라우저에만 저장됩니다. 설정의 **초기화**로 전부 지울 수 있습니다.

## 저장 위치

브라우저 localStorage 키: `secretaryOffice.v1` (대화 3채널, 작업, 메모, API 설정)

## 휴대폰에 앱처럼 설치 (PWA)

`manifest.webmanifest`·`sw.js`·아이콘이 들어 있어, **https 주소**로 연 뒤 브라우저 메뉴에서
**'홈 화면에 추가'(앱 설치)** 를 누르면 전체화면 앱처럼 실행됩니다. (파일을 직접 열면 `file://`이라 설치 안 됨)

- 이름·아이콘: `형근 비서실` / `비서실` · 왕관 아이콘(`icon-192.png`, `icon-512.png`)
- 전체화면(`standalone`), 배경·테마색 `#FAF6EE`(앱 실제 배경색)
- 서비스 워커: 네트워크 우선 + 오프라인 캐시 폴백 → 지하철 등 전파가 끊겨도 마지막 화면이 열립니다
- 대화·메모·설정은 그대로 브라우저 `localStorage`에만 저장 (서버 전송 없음)

## 파일

- `index.html` — 앱 본체 (단일 파일, 외부 라이브러리 없음)
- `manifest.webmanifest` — PWA 설정(이름·아이콘·전체화면·색)
- `sw.js` — 서비스 워커(오프라인 캐시)
- `icon-192.png`, `icon-512.png` — 홈 화면 아이콘(딥네이비 + 황금 왕관)
- `preview.png` — 모바일(412×915) 화면
- `preview-chat.png`, `preview-tasks.png`, `preview-status.png`, `preview-notes.png`, `preview-settings.png`, `preview-desktop.png` — 화면별 확인용 캡처
