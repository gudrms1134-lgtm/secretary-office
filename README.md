# 형근님 비서실 — 사용 안내

`index.html` 파일 하나로 동작하는 멀티 비서실 웹 앱입니다. 서버·빌드 없이 브라우저에서 열면 바로 쓸 수 있습니다.

**v8 — 4명 비서가 각 분야 실전 전문가 버전으로 개편되었습니다.** 직함·답변 방식·시스템 프롬프트가 모두 바뀌었고 서비스워커 캐시는 `secretary-office-v8`입니다.

**휴대폰 설치용 주소(PWA):** <https://gudrms1134-lgtm.github.io/secretary-office/> — 열고 브라우저 메뉴에서 '홈 화면에 추가'

## 여는 방법

- **PC**: `index.html` 더블클릭 (Chrome/Edge 권장)
- **휴대폰**: 파일을 폰으로 옮겨 브라우저로 열기
- **배포**: 이 폴더를 그대로 GitHub Pages / Vercel / Netlify에 올리면 됩니다. (정적 호스팅, 별도 설정 없음)

## 메뉴

| 탭 | 내용 |
|---|---|
| 💬 회의실 | 3개 채널(대회의실·지휘실·라운지) 대화. 채널별로 따로 저장됩니다. |
| 📋 작업실 | 작업 카드 추가 → 시작(진행중) → 완료, 되돌리기, 삭제. 끌어서 옮겨도 됩니다. |
| 📊 비서현황 | 비서 4명의 상태·연결 모델·최근 응답 시간·응답 횟수 |
| 📝 메모 | 자유 메모 작성·수정·삭제 |

## 4명 전문가 역할 (v8)

| 비서 | 직함 | 답하는 방식 |
|---|---|---|
| ㅂ **빵근비서** | **실무 총괄 PM** | 흩어진 요청을 **1·2·3순위 실행 순서 + 체크리스트**로 압축. 맨 끝에 대장님이 피클 "빵근비서"에게 그대로 복사해 넘길 **[최종 액션]** 2~4줄을 붙입니다. 결정이 갈리면 선택지 2개 + 추천 1개. |
| 🤖 **챗GPT 비서** | **생활경제·비용 분석가** | 모든 사안을 **총액·단가·수수료·세금·배송비·시간 대비 가치**로 계산. 계산식과 가정을 그대로 보여주고(예: 12,900원×3 + 배송 3,000원 = 41,700원 → 개당 13,900원), 항목별 비교표와 **손익분기점**을 숫자로 제시합니다. |
| ✨ **제미나이 비서** | **앱테크·구조 분석가** | 이벤트·상품의 **숨은 조건**을 뜯어 '할 만한 것 vs 거를 것'을 판정. 자격 제한·제3자 제공/마케팅 동의·결제·구독 유도·시간 효율·함정(최소 사용·해지·추첨 확률)·실패 손실을 체크합니다. |
| 🧠 **클로드 비서** | **약관·민원·문서 전문가** | 개인정보·계약·환불·보상·약관 리스크를 조항 단위로 짚고, 기관·판매자에게 **바로 복사해 보낼 초안**(사실관계 → 요구사항 → 근거 → 회신 기한)을 씁니다. 협상 단계(1차 문의 → 내용증명·분쟁조정 → 감독기관)까지 안내합니다. |

### 답변 규칙 (v8에서 강화)

- **모호한 역질문 금지** — "어떤 것부터 해드릴까요?", "어떤 기준으로 볼까요?"처럼 공을 되돌리지 않습니다. 질문이 포괄적이어도 가장 현실적인 기준을 스스로 잡아 **결론·기준·초안이 담긴 1차 답**을 먼저 내고, 조건이 꼭 필요할 때만 맨 마지막 줄에서 한 번 확인합니다.
- **검색 OFF에서도 전문가 깊이** — 실시간 가격·오늘 뉴스만 지어내지 않을 뿐, 원리·계산 공식·법적/약관 체크포인트·절차·체크리스트·실전 노하우는 구체적으로 답합니다.
- **@all 중복 금지** — 4명이 함께 답할 때는 자기 전문 각도(총괄 / 비용·숫자 / 조건·함정 / 약관·초안)에서만 3~5줄로 날카롭게 말합니다.

## 회의실 사용법

1. **발신** 칩에서 화자를 고릅니다. 기본은 `👑 형근 (대장님)`입니다.
2. **멘션** 칩(`@all`, `@빵근비서`, `@챗GPT`, `@제미나이`, `@클로드`)을 누르면 입력창에 들어갑니다.
3. 메시지를 보내면 지목된 비서가(멘션이 없으면 총괄 빵근비서가) 먼저
   **"네, 대장님! 실행하겠습니다."**로 응답하고, 이어서 각자 전문 각도에 맞게 답합니다.
4. **방을 넘나들어 기억합니다.** 대회의실에서 `"지휘실에서 나왔던 내용 진행해"`라고 하면
   지휘실의 실제 안건(예: `SM6 타이어 4짝 교체 비교`)을 찾아 그대로 이어서 답합니다.
   비서에게는 매 응답마다 **이 방 최근 20개 + 다른 방 최근 10개씩 + 작업실 할 일 + 메모 + 대장님 기본 정보 + 맞춤 운영 규칙**이 함께 전달됩니다.
   기록에 없는 건 지어내지 않고 "지휘실에 아직 그 건이 안 올라와 있습니다"라고 솔직히 말합니다.
5. 말풍선 오른쪽 **📋** 버튼을 누르면 그 답변이 그대로 복사됩니다. 피클 `빵근비서`에게 붙여넣어 실제 실행을 넘길 때 쓰세요. 메모 카드에도 **📋 복사**가 있습니다.

## AI 연결 (⚙️ API 설정)

키가 없으면 **데모 모드**로 응답합니다. 데모 모드에서도 **채널의 앞뒤 대화를 읽고 이어서** 답합니다(인사·잡담·질문·후속 대답·지시를 구분하고, "아까 내가 뭐라고 했어?"처럼 물으면 실제 앞 발화를 인용). 키를 넣으면 실제 모델이 답합니다.

| 방법 | 키 | 사용되는 비서 |
|---|---|---|
| **Gemini 키 하나 (가장 간단)** | `AIza...` 또는 `AQ....` | **4명 전부** (빵근·챗GPT·제미나이·클로드 — 각자 역할·말투 유지) |
| OpenRouter | `sk-or-v1-...` | 4명 전부 (빵근·챗GPT·제미나이·클로드) |
| 개별 키 | OpenAI `sk-...` | 빵근비서, 챗GPT 비서 |

- **Gemini 키 하나면 4명 전원이 실제 AI**: 자동 모드에서 OpenRouter·OpenAI 키가 없어도, Gemini 키만 있으면 빵근·챗GPT·클로드까지 Gemini 모델을 호출합니다(각 비서의 역할·말투는 system prompt로 유지). 상단 칩이 `실제 AI 연결 (4/4)`로 바뀝니다.
- **Gemini 기본 모델**: `gemini-flash-lite-latest` (무료 등급·저지연). 단종·혼잡(404/503)이면 `gemini-3.5-flash-lite` → `gemini-3.8-flash` 순으로 자동 재시도합니다. 모델 지정을 비우면 이 값이 쓰입니다.
  - 2026-11-27 실측: `gemini-flash-lite-latest`·`gemini-3.5-flash-lite`는 **0.6~1.2초 200**, `gemini-3.8-flash`는 **503(11초 대기) 또는 응답 25초** — 그래서 기본값은 flash-lite를 유지하고 3.8-flash는 마지막 비상용(15초 제한)으로만 둡니다.
- **키 전달 방식**: `x-goog-api-key` 헤더로 보내며 `AIza…`·`AQ.…` 두 형식 모두 동작합니다.

- **연결 모드**: `자동`(입력된 키 우선, Gemini 키 하나로도 4명 전원) / `OpenRouter` / `개별 키`(전용 키 우선, 없으면 Gemini 키로 대체) / `데모`
- **맥락 전달**: 실제 모드에서는 ① 이 방 최근 **20개** 대화 ② 다른 두 방 최근 **10개씩** ③ 작업실 할 일(상태별) ④ 메모 ⑤ 대장님 기본 정보 ⑥ 맞춤 운영 규칙을 함께 보냅니다. 다른 방 이름이 나오면 그 기록에서 실제 안건을 찾아 답합니다.
- **OpenRouter 크레딧**: 5달러를 충전해 두면 4명 전원이 유료 가성비 모델로 답합니다. 크레딧이 0이 되면 402(결제 필요) 오류가 나고, 채팅에 "OpenRouter 크레딧이 부족합니다 — 충전하거나 :free 모델로 바꾸세요" 안내가 남습니다(401이면 키 오류 안내).
- **모델 지정**을 펼치면 비서별 모델명을 직접 바꿀 수 있습니다. 비워두면 기본값을 씁니다.
  - 기본값(OpenRouter, 2026-11-27 `openrouter.ai/api/v1/models` 실제 목록·단가 확인):

    | 비서 | 모델 ID | 입력/출력 (100만 토큰) | 컨텍스트 |
    |---|---|---|---|
    | 빵근(실무 총괄 PM) | `openai/gpt-6-luna` | $0.10 / $0.50 | 1,050,000 |
    | 챗GPT(생활경제·비용) | `openai/gpt-6-luna` | $0.10 / $0.50 | 1,050,000 |
    | 제미나이(앱테크·구조) | `google/gemini-3.5-flash-lite` | $0.30 / $2.50 | 1,048,576 |
    | 클로드(약관·민원·문서) | `anthropic/claude-haiku-5.5` | $0.10 / $0.50 | 1,000,000 |

    - 5달러 예상 사용량: 답변 1건(입력 6천·출력 5백 토큰) 기준 약 **$0.0009~0.003** → **하루 10건 안팎이면 1년 가까이**, `@all`로 하루 30건 이상 쓰면 4~6개월입니다. 단가가 더 낮은 모델로 바꾸면 그만큼 늘어납니다.
    - 지정한 모델이 단종·미지원(404)이거나 본문이 비면 `openai/gpt-4o-mini` → `google/gemini-2.5-flash-lite` 순으로 자동 재시도하고, 비서현황에 실제 답한 모델을 `→ 모델명`으로 표시합니다.
    - 추론형 모델(GPT-6·Claude 5 계열)에는 `temperature` 대신 `reasoning.effort: low`를 보내 응답을 빠르게 유지합니다. 파라미터 미지원(400)이면 그 파라미터만 빼고 한 번 더 시도합니다.
  - 기본값(Gemini 키 사용 시): 4명 모두 `gemini-flash-lite-latest`
- **🔌 연결 테스트**로 키가 실제로 동작하는지 바로 확인할 수 있습니다.
- **🌐 실시간 웹 검색 (ON/OFF)**: 회의실 입력창 위 `검색` 줄의 `🌐 웹검색 ON/OFF` 칩으로 켜고 끕니다(설정은 브라우저에 저장).
  - **OpenRouter 키가 있을 때만** 켜집니다. 데모·Gemini·OpenAI 전용 모드에서 누르면 "OpenRouter 모드에서 지원됩니다" 안내가 뜨고 켜지지 않습니다.
  - ON이면 OpenRouter 요청 본문에 공식 웹 플러그인 `plugins: [{ id: 'web', max_results: 3 }]`를 붙여 최신 가격·날짜·사실을 검색합니다. 400으로 거부되면 모델명 `:online` suffix로 1회 재시도, 그것도 안 되면 플러그인 없는 일반 모델로 폴백합니다.
  - 응답에 URL 출처(`annotations`)가 있으면 말풍선 하단에 **🌐 출처** 링크(최대 3개)로 붙습니다.
  - 시스템 프롬프트도 ON일 때 "실시간 웹 검색 결과가 함께 제공된다 · 검색에 없는 숫자는 지어내지 마라"로 바뀝니다.
  - **비용**: 웹 검색은 회당 약 **$0.02**(모델 토큰 비용 별도). `@all`로 4명이 동시에 답하면 4배이므로, 필요할 때만 켜고 끝나면 다시 눌러 끄세요.
  - Gemini 경로(Gemini 키로 답하는 비서)에는 웹 플러그인이 적용되지 않습니다.
- API 호출이 실패하면(키 오류·CORS 차단 등) 응답을 데모로 대체하고 채팅에 안내 문구를 남깁니다.

> 키는 이 브라우저의 `localStorage`에만 저장되고 서버로 전송되지 않습니다.
> 대화·작업·메모도 모두 이 브라우저에만 저장됩니다. 설정의 **초기화**로 전부 지울 수 있습니다.

## 메모 기본값

첫 실행(또는 업데이트 후 첫 새로고침) 때 **📌 대장님 맞춤 운영 규칙** 메모가 1개 들어갑니다.
사업자 등록 불가·현금 과다 지출/고위험 투자/개인정보 제3자 제공 금지, 무비용·저비용·실속 우선,
웹에서 되는 합법적 포인트·공공기관 경품·체험단·생활 절약·자동화, 피클에 복사해 넘길 실행 단위,
**전문가 규칙(모호한 역질문 금지·검색 OFF 전문가 깊이·@all 각자 각도)**, 결론부터 3~6줄 말투 — 이 내용이 **모든 비서의 시스템 프롬프트에도 함께 들어갑니다.**
기존 사용자에게도 v5·v8 규칙 두 줄이 각각 한 번씩만 자동으로 덧붙습니다.
수정·삭제는 메모 탭에서 하시면 되고, 지우면 다시 생기지 않습니다.

## 휴대폰에 앱처럼 설치 (PWA)

`manifest.webmanifest`·`sw.js`·아이콘이 들어 있어, **https 주소**로 연 뒤 브라우저 메뉴에서
**'홈 화면에 추가'(앱 설치)** 를 누르면 전체화면 앱처럼 실행됩니다. (파일을 직접 열면 `file://`이라 설치 안 됨)

- 이름·아이콘: `형근 비서실` / `비서실` · 왕관 아이콘(`icon-192.png`, `icon-512.png`)
- 전체화면(`standalone`), 배경·테마색 `#FAF6EE`(앱 실제 배경색)
- 서비스 워커: 네트워크 우선 + 오프라인 캐시 폴백 → 지하철 등 전파가 끊겨도 마지막 화면이 열립니다 (v8 캐시: `secretary-office-v8`)
- 대화·메모·설정은 그대로 브라우저 `localStorage`에만 저장 (서버 전송 없음)
